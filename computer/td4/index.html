TD4 4ビットCPU 回路シミュレーター

書籍『CPUの創りかた』で知られる4ビットCPU「TD4」を、NOT・AND・OR・XORゲートとDフリップフロップだけで組み立て、ゲート単位でシミュレーションします。クロックを1つずつ進めて、命令が回路をどう流れるかを確認できます。

回路図 オレンジ＝値が0以外のバス／青の点線＝有効な制御信号

制御信号 命令デコーダの出力

ROM（プログラム） ビットをクリックするとDIPスイッチを切り替えます

アセンブラ 命令を書いて ROM に書き込みます（最大16命令）

数値は 10進（5）、2進（0b0101）、16進（0x5）で書けます。「;」以降はコメントです。

命令一覧 上位4bit＝命令、下位4bit＝Im（即値）

命令機械語動作
ADD A,Im0000 ImA ← A + Im（桁上がりは C へ）
ADD B,Im0101 ImB ← B + Im
MOV A,Im0011 ImA ← Im
MOV B,Im0111 ImB ← Im
MOV A,B0001 0000A ← B
MOV B,A0100 0000B ← A
IN A0010 0000A ← 入力
IN B0110 0000B ← 入力
OUT B1001 0000OUT ← B
OUT Im1011 ImOUT ← Im
JMP Im1111 ImPC ← Im
JNC Im1110 ImC = 0 のとき PC ← Im

C フラグは毎クロック、加算器の桁上がりで上書きされます。JNC は直前の命令の桁上がりを見ます。

回路の規模 このシミュレーターが実際に計算しているゲート数

各ゲートは毎クロック、配線のつながり順（トポロジカル順）にすべて計算されます。レジスタは立ち上がりで値を取り込む D フリップフロップです。

ゲート単位のシミュレーションです。電気的な遅延やチャタリングは扱いません。
